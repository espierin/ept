# EFI EPT Insights

## Concept and development

A research prototype for HLA single antigen bead analysis within EPT. The documentation describes structure, intended inputs and outputs, and EFI styling. The browser prototype is available online. Selected files are processed in your browser only; there is no central reception or storage.
